# 색 영역 모드 UI: 모드 전환 · 필라멘트 개수·색 선택 · 미리보기 · 다운로드 (2/2)

## Goal / Non-goals
- Goal: 1/2 의 코어를 웹 UI 에 연결한다. 모드 전환("흑백 층"(기존 그대로) / "색 영역"), 색 영역 모드의 "1. 필라멘트(개수 1~4, 슬롯별 색) → 2. 이미지 → 3. 옵션" 흐름, 색 영역 2D 미리보기(분류된 색 합성), 색 영역을 칠한 3D 뷰어, 다중 파트 3MF 다운로드. 색 영역 모드에는 톤 단계·이미지 보정 컨트롤이 없고 높이(베이스 두께)·크기·픽셀 간격·모서리 라운드만 있다. 흑백 층 모드 화면·동작은 그대로다.
- Non-goals: 톤 단계·그레이스케일·이미지 보정·명도 높이(색 영역 모드에서 제거됨) / 층 쌓기·쌓는 순서 선택 / 색 교체 방식 / 베이스 슬롯 / 분류 규칙 조절 / 작은 조각 정리 / 슬롯별 소재 설정 / 코어 로직 변경(1/2 의 책임). (참고: 모바일 3D 뷰어가 세로 화면에서 모델 좌우가 잘리는 기존 문제는 이 계획의 범위 밖이다.)
