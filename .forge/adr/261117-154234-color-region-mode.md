# 다색 출력은 이미지 위치를 가장 가까운 필라멘트 색으로 칠하는 색 영역 모드로 하고 높이는 명도로 정한다

## Status
accepted

사용자가 컬러 일러스트(검은 외곽선, 흰 몸, 분홍 볼)를 올렸을 때 분홍 부분이 분홍으로 출력되길 원한다. 높이 구간으로 색을 나누는 층 방식(ADR 261117-143215, 261117-152717)과 채도 기준 분류의 색 그룹 방식(ADR 261117-150705)은 이 의도를 만족하지 못한다. 그래서 **색 영역 모드**를 추가한다. 필라멘트 1~4개의 색을 고르면 이미지의 각 셀을 Lab 색 거리(명도 포함)가 가장 가까운 색 하나로 분류하고, 색마다 별도 파트(필라멘트 지정)로 출력한다. 모든 셀의 높이는 같다(스냅된 베이스 두께, 사용자가 조절). 명도·그레이스케일·톤 단계는 쓰지 않는다. 필라멘트 1개는 파트 1개로 높이만 조절하는 단색 판이다. 흑백 2색 층 모드(ADR 261116-134329)는 그대로 둔다.

## Considered Options
- 높이 구간별 색 층 쌓기(K=1~4, 쌓는 순서 선택) — 높이가 같은 모든 위치가 같은 색이 되어 분홍 볼 같은 영역을 칠할 수 없어 폐기.
- 채도(a*b*)만으로 분류 + 베이스 슬롯 — 검정과 흰색이 구분되지 않고 옅은 색(분홍, 살색)이 중립 슬롯으로 가서 폐기.
- 높이를 명도(톤 단계)로 정하는 릴리프 — 처음에 선택했으나, 그레이스케일 과정이 의도와 달라 폐기(아래 Amendment).
- 반투명 적층 혼합(HueForge식) — 물리 파라미터가 필요하고 검증이 어려워 제외.

## Consequences
- 다중 파트 3MF가 Bambu Studio에서 파트별 필라멘트 지정대로 열리는지는 단위 테스트로 검증할 수 없고 참고 파일도 없다. 작은 샘플로 먼저 수동 확인한 뒤 UI를 만든다.
- 한 레이어 안에서 필라멘트가 자주 바뀌어 출력 시간과 퍼지 낭비가 크게 늘어난다.
- 색 영역 모드에는 이미지 보정(밝기·대비·감마·반전)과 톤 단계가 없다. 색 분류는 원본 색의 Lab 거리로만 한다.

## Amendment (2026-11-17)
처음에는 높이를 명도(톤 단계)로 정하기로 했지만(밝을수록 높음), 사용자가 "색상별 그레이스케일 과정"을 버리고 다시 만들기를 요청했다. 그래서 높이는 모든 색 영역에서 같고(베이스 두께), 톤 단계·이미지 보정·명도 높이는 색 영역 모드에서 쓰지 않는다. 색 분류 규칙(Lab 최근접)과 색별 파트 구조는 그대로다.

## Amendment 2 (2026-11-17)
동작은 필라멘트 개수로 갈린다. 1개: 그레이스케일 톤 단계를 높이로만 쓰는 단색 릴리프. 2개: 기존 흑백 층 모드 그대로(베이스 색 위에 두 번째 색을 톤 단계만큼 쌓고 색 교체 1회), 색만 고를 수 있다. 3개 이상: 색 영역 모드 — 각 셀을 Lab 최근접 색으로 나누고, 높이는 1~2개일 때와 같은 그레이스케일 톤 단계(밝을수록 높음)로 정한다. 즉 Amendment 1의 "평평한 높이"는 철회하고, 3개 이상의 높이는 흑백 모드와 같은 파이프라인(밝기·대비·감마·반전 포함)을 쓴다. 영역 안 단계를 두께 농담(베이스 위 적층)으로 표현하는 안은 기각했다(색이 섞여 미리보기와 출력이 달라짐).

## Amendment 3 (2026-11-17)
3개 이상에서 색 파트를 바닥부터 통째로 만들면 그림이 바닥면에도 나오고(양면) 베이스 구간에서도 매 레이어 필라멘트가 바뀐다. 그래서 슬롯 1 색을 베이스로 쓴다: 바닥부터 베이스 두께까지는 슬롯 1 색의 판이고, 나머지 색은 베이스 윗면부터만 올린다. 모든 셀은 톤 높이보다 1레이어 더 높게 만들어, 가장 어두운 톤 단계(높이 = 베이스)에서도 자기 색이 한 층은 나오게 한다. 베이스 색을 따로 고르는 UI 는 두지 않았다.
