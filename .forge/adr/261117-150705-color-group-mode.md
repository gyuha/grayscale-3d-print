# 다색 출력은 높이 층 교체가 아니라 컬러 그룹 모드(그룹별 파트 + 흰 베이스 위 두께)로 한다

## Status
superseded by ADR 261117-154234 (색 그룹 방식은 채도 분류의 한계로 폐기)

AMS 여러 색을 쓰려는 의도는 "이미지의 색을 여러 색 그룹으로 나누고 그룹마다 명도를 단계로 나누는 것"이다. 높이 구간마다 필라멘트를 바꾸는 방식(ADR 261117-143215)은 한 높이의 모든 픽셀이 같은 색이 되어 이 의도를 만족하지 못한다. 그래서 흑백 2색 층 모드(ADR 261116-134329)는 그대로 두고, 별도의 **컬러 그룹 모드**를 추가한다. AMS 슬롯 4개 중 하나는 베이스(전체 판, 기본 흰색), 나머지 3개는 색 그룹이다. 픽셀은 Lab 색도(a*b*) 거리가 가장 가까운 슬롯 색의 그룹에 들어가고, 명도(L*)는 그룹 안에서 두께로 표현한다(밝을수록 얇고 단계 0은 베이스만 보임, 단계 k는 k×m 레이어). 그룹마다 별도 파트로 베이스 윗면 위에 올리고 파트에 필라멘트 슬롯을 지정한다.

## Considered Options
- 높이 구간별 색(층 방식) K색 — 의도와 달라 폐기. 구현은 git stash로 보관했고 필라멘트 배열 확장 코드만 재사용한다.
- HSV 색상각 분류 + 무채색은 베이스만 — 어두운 무채색을 표현할 수 없어 기각.
- 4슬롯 모두 색 그룹(베이스 없음) — 밝은 쪽 표현력이 떨어져 기각. 베이스 슬롯은 사용자가 고른다.
- 반투명 적층 혼합(HueForge식) — 물리 파라미터 필요, 검증 곤란.

## Consequences
- 다중 파트 3MF가 Bambu Studio에서 파트별 필라멘트 지정대로 열리는지는 단위 테스트로 검증할 수 없다(원본 3MF는 단일 파트). 수동 확인이 필요하며 실패하면 이 결정의 파트 구조를 재검토한다.
- 같은 레이어 안에서 필라멘트가 자주 바뀌어 출력 시간과 퍼지 낭비가 크게 늘어난다. 얇은 색 층이 흰 베이스 위에서 어떻게 보이는지는 필라멘트마다 달라 출력해 봐야 안다.
- 색 그룹은 3개로 제한된다(베이스가 슬롯 하나를 차지).
