# 다색 출력은 필라멘트 1~4개를 높이 구간으로 쌓는 층 방식으로 하고, 쌓는 순서를 사용자가 고른다

## Status
superseded by ADR 261117-154234 (층 쌓기 방식은 색 영역을 칠할 수 없어 폐기)

사용자 흐름은 "1. 필라멘트 개수(1~4)와 색·쌓는 순서 선택 → 2. 이미지 선택 → 3. 옵션 조정"이다. 밝기를 높이로 바꾸고 높이 구간마다 필라멘트를 쌓는다: 1개면 색 교체 없이 높이만(단색 릴리프), 2개면 흑백 층 모드와 같은 구조에 색과 순서만 사용자가 고르고, 3~4개면 색 구간을 추가로 쌓는다(색 교체 K-1회). 쌓는 순서는 AMS 슬롯 번호와 별개이며, 색 교체의 `extruder`는 그 위치의 슬롯 번호다. 베이스(첫 층)의 필라멘트는 쌓는 순서의 첫 슬롯이다. 구간 규칙은 ADR 261117-143215를 그대로 따른다(베이스 색은 톤 단계 0만, 나머지 단계를 나머지 색이 균등 분배, N≥K). 프라임 타워는 만들어도 되지만 템플릿 값(꺼짐, 참조 3MF와 동일)을 유지한다.

## Considered Options
- 이미지 색상 그룹별 파트 + 그룹 안 명도 두께(ADR 261117-150705) — 사용자 의도(층 쌓기)와 달라 폐기. 구현은 git stash에 보관.
- 반투명 적층 혼합(HueForge식) — 이번에는 제외. 얇은 층이 비쳐서 생기는 중간색은 출력해 봐야 알 수 있다.
- 슬롯 번호 순서로만 쌓기 — 사용자가 쌓는 순서를 고를 수 없어 기각.

## Consequences
- 3~4색 3MF가 Bambu Studio에서 올바르게 로드되고 색 교체가 의도한 레이어에 걸리는지, 쌓는 순서를 바꿨을 때 베이스 필라멘트가 맞는지는 단위 테스트로 검증할 수 없다. 수동 확인이 필요하다.
- 톤 단계 수 N은 색 수 K 이상이어야 한다(K=1은 제한 없음).
