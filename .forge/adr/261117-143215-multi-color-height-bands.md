# 톤을 2색 고정에서 K색(2~4) 높이 구간으로 확장한다

## Status
superseded by ADR 261117-154234 (K색 높이 구간 방식은 색 영역을 칠할 수 없어 폐기)

AMS 4색을 쓰기 위해, 색 교체를 1회로 고정한 구조를 K색(K=2..4)·K-1회 교체로 일반화한다. 베이스 색은 톤 단계 0만 맡고, 나머지 톤 단계 1..N-1을 나머지 K-1색이 균등 분배한다(색 c는 단계 1+floor((k-1)(K-1)/(N-1))). 각 색 교체 `top_z`는 그 색이 맡는 첫 단계 바로 아래 단계의 높이 + 1레이어다. K=2이면 기존 출력과 같다. 색은 사용자가 슬롯 순서대로 고른다.

## Considered Options
- 반투명 적층 혼합(HueForge식) — 필라멘트별 투과 거리 같은 물리 파라미터가 필요하고 미리보기 정확도를 보장할 수 없어 기각.
- 경계를 사용자가 직접 조절 — UI·검증이 늘어나 이번에는 제외, 자동 규칙만 둔다.
- N단계를 K색에 균등 분배 — K=2일 때 기존 출력(검정은 단계 0만)이 바뀌어 기각.

## Consequences
- 4색 3MF가 Bambu Studio에서 올바르게 로드되고 색 교체 3회가 의도한 레이어에 걸리는지는 단위 테스트로 검증할 수 없다. 수동 확인이 필요하며, 실패하면 이 결정(특히 `project_settings` 필라멘트 배열 확장 방식)을 재검토한다.
- 톤 단계 수 N은 색 수 K 이상이어야 한다.
